# Vector Search in Meilisearch

Vector search is a powerful feature in Meilisearch that allows you to search for similar documents based on their semantic meaning rather than just keyword matches. This guide will walk you through the basics of vector search, how to index vector data, and how to perform vector and hybrid searches in Meilisearch.

## What is Vector Search?

Vector search uses numerical representations (vectors) of documents or queries to find similarities. These vectors are typically generated by machine learning models and capture the semantic meaning of the text. This allows for more nuanced and contextually relevant search results compared to traditional keyword-based searches.

## Indexing Vector Data

To use vector search in Meilisearch, you need to index your documents with vector representations. Here's how you can do it:

1. Choose an embedding model: Meilisearch supports various embedding models, including Hugging Face models, OpenAI, and custom REST API-based models.

2. Generate embeddings: Use the chosen model to generate vector embeddings for your documents.

3. Add documents with embeddings: When adding documents to your Meilisearch index, include the vector embeddings alongside other document fields.

Example of adding a document with vector data:

```json
{
  "id": 1,
  "title": "Introduction to Vector Search",
  "content": "Vector search is a powerful technique for finding similar documents.",
  "_vectors": {
    "default": [0.1, 0.2, 0.3, ..., 0.9]
  }
}
```

## Performing Vector Searches

To perform a vector search, you need to provide a query vector. This can be generated from a text query using the same embedding model used for indexing.

Here's an example of how to perform a vector search:

```rust
let mut search = Search::new(rtxn, index);
search.semantic(
    "default",
    Arc::new(embedder),
    false,
    Some(query_vector)
);
let search_result = search.execute()?;
```

In this example:
- `"default"` is the name of the embedder used
- `embedder` is an instance of the `Embedder` struct
- `false` indicates that the vectors are not quantized
- `query_vector` is the vector representation of the search query

## Hybrid Search

Meilisearch also supports hybrid search, which combines vector search with traditional keyword-based search. This can provide more accurate and relevant results by leveraging both semantic similarity and exact keyword matches.

To perform a hybrid search, you can use both the `query` and `semantic` methods on the `Search` struct:

```rust
let mut search = Search::new(rtxn, index);
search.query("keyword query");
search.semantic(
    "default",
    Arc::new(embedder),
    false,
    Some(query_vector)
);
let search_result = search.execute()?;
```

## Supported Embedding Models

Meilisearch supports several types of embedding models:

1. Hugging Face models
2. OpenAI models
3. Ollama models
4. Custom REST API-based models
5. User-provided embeddings

You can choose the appropriate model based on your specific needs and use case.

## Best Practices

1. Choose the right embedding model: Select a model that is appropriate for your domain and language.

2. Optimize vector dimensions: Balance between accuracy and performance. Higher dimensions can provide more accurate results but may impact search speed.

3. Use hybrid search: Combine vector search with keyword search for more comprehensive results.

4. Index management: Regularly update your vector embeddings if the underlying data changes to ensure search relevance.

5. Performance tuning: Experiment with different `limit` and `offset` values to optimize search performance and result quality.

6. Caching: Meilisearch implements caching for embeddings to improve performance. Take advantage of this by reusing similar queries when possible.

By following these guidelines and leveraging Meilisearch's vector search capabilities, you can create powerful and semantically meaningful search experiences for your users.
